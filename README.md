# GD-Auto-Rate
Automatic geometry dash level rating macro for the annoying rate achievements

## Installation
On the right, click on the latest release and download and unzip **GD Auto Rate.zip**

## How to use
1. Have GD open with **No Fullscreen** and **1920x1080** resolution (preferably High texture quality)
2. Head to the **recent tab** or any level tab with rate-able levels (no already rated levels or demons)
3. Open the macro, click into GD and press F1
4. Done! Press F2 whenver you want to stop
   
## Notes
- **Do not** use any texture packs
- Enable the **No Transition** check if you have the No Transition hack on
- Windows might flag this as a false positive due to automated inputs
